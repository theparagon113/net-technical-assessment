## Historical reconciliation findings (checkpoint before M4)

The second executable host, canonical requirements, and explicit traceability were missing from the initial plan and have been added. Further gaps were explicit public endpoint planning, deterministic shared database configuration, cross-host token testing, two frontend base URLs, and final REST GenAI evidence. These are now assigned above and in the M4–M8 roadmap; they are not implemented by this checkpoint. No forbidden technology was found. No separate presentation notes previously existed; a preparation outline now exists, not a completed presentation.


## M4 audit

M4A/B/C are complete. Two executable controller hosts expose their assigned endpoints with shared absolute SQLite/JWT configuration. Automated tests prove Task.Api-first schema/no seed, Auth.Api seed after initialization, common storage despite different actual content roots, concurrent/repeated startup preservation, actual HTTP login JWT acceptance across hosts, and cross-user isolation for every relevant CRUD operation. Existing 65 Application and 48 Infrastructure cases remain green; 78 HTTP/startup cases were added (191 total). Package inventory contains no forbidden dependencies.

The 47 IDs remain unchanged. HTTP/backend/REST-output rows had real evidence at M4; frontend, browser, final clean-clone review and presentation rows remained explicitly incomplete at that milestone. The historical reconciliation findings above describe that checkpoint, not the current implementation state. See the subsequent M5 audit below.
