Further gaps were explicit public endpoint planning, deterministic shared database configuration, cross-host token testing, two frontend base URLs, and final REST GenAI evidence. These are now assigned above and in the M4–M8 roadmap; they are not implemented by this checkpoint. No forbidden technology was found. No separate presentation notes previously existed; a preparation outline now exists, not a completed presentation.
